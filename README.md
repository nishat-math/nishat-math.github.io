# গণিতের গ্রাম

প্রথম শ্রেণির গণিতের খেলা (Room to Read Grade 1 worksheets অনুসারে)। ঠিকানা: https://nishat-math.github.io

- প্রতিটি অধ্যায় একটি লেভেল, প্রতিটি ওয়ার্কশিট পাতা একটি দিন।
- শিক্ষার্থীরা শ্রেণি কোড, নাম ও ফোন নম্বর দিয়ে ঢোকে। ফলাফল শিক্ষকের নিজের Google Sheet-এ জমা হয় (js/config.js-এ backendUrl)।
